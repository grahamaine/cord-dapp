Do it yourself

Verify without this page

  1. Open the anchor transaction on CCDExplorer. Its registered data reads cord:audit:v1|a=<seq>:<hash>|r=<seq>:<hash>.
  2. Download the records as JSON. Each audit entry's hash is SHA-256 of the entry's JSON without the hash; each prevHash is the previous entry's hash.
  3. Recompute the chain up to entry <seq>: it must end in exactly the anchored hash.
  4. Or clone the repo and run npm run audit:verify next to the records.
