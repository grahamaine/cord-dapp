Suppliers on other blockchains verify an Ethereum, Base or Solana agent through its link to Concordium

A supplier agent on another chain can link its key to a Concordium agent (CIS-8). Cord looks the key up, finds the linked agent and its identity-verified owner, and runs the same badge check. Payment still settles on Concordium, to that verified owner.

EVM addresses don't reveal their key: paste the public key, or let the supplier sign once with MetaMask.
